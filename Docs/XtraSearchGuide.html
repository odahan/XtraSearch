Guide d’utilisation

Recherchez des fichiers par nom ou par contenu dans les dossiers et les partages réseau que vous sélectionnez.

Lancer une recherche

  1. Dans Look in, indiquez un dossier ou choisissez-le avec Browse…. Séparez les chemins par ; et préfixez les exclusions par !. Vous pouvez utiliser une variable comme %TEMP%.
  2. Dans File name, saisissez * pour tous les fichiers ou *.txt;*.log pour limiter la recherche à deux extensions.
  3. Saisissez du texte dans Containing text, ou laissez ce champ vide pour chercher uniquement par nom. Lancez avec Start search, Ctrl+Entrée ou F5.

Chaque liste déroulante conserve les dix dernières valeurs distinctes utilisées dans son champ.

Choisir le mode de recherche

  • Dans Options, le mode Wildcards de File Name utilise * pour une suite de caractères et ? pour un caractère. Un nom simple sans joker ni point peut correspondre à une partie du nom.
  • Regular Expression accepte une expression régulière, par exemple error\s+\d+.
  • Boolean accepte AND, OR, NOT, les guillemets et les parenthèses. Entourez une expression littérale de guillemets, comme dans "connection failed" AND NOT timeout.
  • Les termes peuvent correspondre sur des lignes différentes. Activez Match Boolean expressions line by line dans Options pour exiger une correspondance sur une seule ligne. Match case se règle séparément pour le nom et le contenu.

Tester une expression régulière

  1. Dans Options, choisissez Regular Expression pour le nom ou le contenu. Revenez dans Main et cliquez sur Test… à côté du champ correspondant.
  2. Saisissez votre expression. Collez un échantillon ou utilisez Load sample… pour charger un fichier texte. Pour tester des noms de fichiers, saisissez un nom par ligne. Pour le contenu, chaque ligne est testée séparément.
  3. Consultez le nombre de lignes et de correspondances. Les flèches parcourent les correspondances surlignées et affichent les groupes capturés. En cas d’erreur de syntaxe, Go to position place le curseur à l’endroit indiqué par le moteur.
  4. Cliquez sur Use pattern pour appliquer le motif et les options de correspondance au champ d’origine sans lancer la recherche.

Dans le panneau Syntax, cliquez sur un fragment .NET, comme \d pour un chiffre ou \b pour une limite de mot, pour l’insérer. Examples charge un motif et son échantillon. Utilisez Escape literal text pour insérer un texte exact dont les caractères spéciaux sont échappés.

Affiner les critères

Include subfolders parcourt les sous-dossiers. Whole words limite la recherche de contenu aux mots entiers. Dans Options, réglez l’inclusion des fichiers masqués ou système, l’exclusion du contenu binaire et le nombre de workers (0 pour le mode automatique).

Dans Size & Dates, les limites de taille sont strictes et exprimées en Ko de 1 024 octets. Saisissez les dates de création ou de modification au format yyyy-MM-dd ou choisissez-les dans le calendrier. Les jours renseignés sont inclus en entier.

Formats pris en charge

La recherche de contenu prend en charge le texte UTF-8, l’Unicode avec marque BOM, les PDF contenant du texte, les fichiers DOCX, XLSX, PPTX et les documents OpenDocument.

Activez Search inside ZIP archives pour lire les entrées ZIP comme du texte. Les archives imbriquées et la reconnaissance de texte dans les PDF numérisés ne sont pas prises en charge.

Consulter les résultats

Pause suspend la recherche. Resume la reprend. Stop ou Échap l’arrête et conserve les résultats trouvés.

Pendant une recherche de contenu en parallèle, cliquez sur le nombre de threads dans la barre d’état pour voir le fichier traité, le temps écoulé et le nombre de lignes lues pour chaque thread. Faites glisser le séparateur pour redimensionner le volet.

Sélectionnez un résultat pour afficher son aperçu. Ouvrez un fichier avec Entrée ou un double-clic. Utilisez Folder pour le localiser, Copy path pour copier son chemin et Search log pour consulter les erreurs.

Un clic droit sur un résultat, ou la touche menu / Maj+F10, ouvre le menu contextuel classique de Windows. Pour un résultat dans un ZIP, le menu concerne l’archive. Si le fichier n’existe plus, un message s’affiche.

Enregistrer ou exporter

Save search enregistre vos critères. Open… les recharge. Dans le volet des résultats, Export… est disponible dès qu’un résultat apparaît. Choisissez un fichier CSV, un fichier texte ou un rapport HTML.

Au-delà de 100 résultats, une boîte de dialogue affiche le total et le propose par défaut. Saisissez un entier compris entre 1 et ce total pour exporter uniquement les premières lignes, puis cliquez sur Continue pour choisir le fichier de destination.

Le rapport HTML est un fichier autonome en thème sombre. Il affiche la date et l’heure d’export avec le décalage UTC, ainsi que le nombre de résultats exportés sur le total, par exemple 100 / 250 results exported. Les noms de fichiers sont des liens vers les fichiers d’origine. Pour une entrée ZIP, le lien pointe vers l’archive.

Search guide

Find files by name or by the text they contain in the folders and network shares you select.

Start a search

  1. Enter a folder in Look in or select it with Browse…. Separate paths with ; and prefix exclusions with !. Environment variables such as %TEMP% are supported.
  2. In File name, enter * for all files or *.txt;*.log to limit the search to two extensions.
  3. Enter text in Containing text or leave it blank to search by name alone. Choose Start search or press Ctrl+Enter or F5.

Each drop-down remembers the ten most recent distinct values used in that field.

Choose a matching mode

  • In Options, the Wildcards mode for File Name uses * for any number of characters and ? for one character. A simple name without a wildcard or dot can match part of a file name.
  • Regular Expression accepts a regular expression such as error\s+\d+.
  • Boolean accepts AND, OR, NOT, quoted phrases, and parentheses. Use quotation marks for a literal phrase, as in "connection failed" AND NOT timeout.
  • Content terms can match across lines. Enable Match Boolean expressions line by line in Options to require a match on a single line. Set Match case separately for file names and content.

Test a regular expression

  1. In Options, select Regular Expression for the file name or contents. Return to Main and click Test… next to the corresponding field.
  2. Enter your pattern. Paste a sample or choose Load sample… to load a text file. When testing file names, enter one name per line. When testing contents, each line is checked separately.
  3. Review the line and match counts. Use the arrows to move through highlighted matches and inspect captured groups. If the pattern has a syntax error, Go to position moves the cursor to the location reported by the regex engine.
  4. Choose Use pattern to apply the pattern and matching options to the original field without starting a search.

In the Syntax pane, click a .NET regex fragment such as \d for a digit or \b for a word boundary to insert it. Examples loads a pattern and sample. Use Escape literal text to insert exact text with its special characters escaped.

Narrow the search

Include subfolders searches nested folders. Whole words limits content matches to whole words. In Options, control hidden and system files, binary content, and parallel search workers (0 for automatic).

In Size & Dates, size limits are exclusive and use KB of 1,024 bytes. Enter creation or modification dates as yyyy-MM-dd or choose them from the calendar. The specified dates include the entire day.

Supported formats

Content search supports UTF-8, BOM-marked Unicode, PDFs with embedded text, DOCX, XLSX, PPTX, and OpenDocument files.

Enable Search inside ZIP archives to read ZIP entries as text. Nested archives and OCR for scanned PDFs are unsupported.

Review results

Pause suspends the search. Resume continues it. Stop or Esc ends the search and keeps results found so far.

During a parallel content search, click the thread count in the status bar to see the file, elapsed time, and lines read for each thread. Drag the divider to resize the pane.

Select a result to preview it. Open a file with Enter or a double-click. Use Folder to locate it, Copy path to copy its path, and Search log to review errors.

Right-click a result, or press the menu key / Shift+F10, to open the classic Windows context menu. For a ZIP entry, the menu targets the archive. If the file no longer exists, a message is shown.

Save or export

Save search stores your criteria. Open… loads them again. Export… becomes available in the results pane as soon as a result appears. Choose a CSV file, a text file, or an HTML report.

When there are more than 100 results, a dialog shows the total and fills in that value by default. Enter a whole number from 1 to the total to export only the first rows, then click Continue to choose where to save the file.

The HTML report is a standalone file with a dark theme. It shows the export date and time with the UTC offset, and the number of exported results out of the total, for example 100 / 250 results exported. File names link to the original files. For a ZIP entry, the link points to the archive.

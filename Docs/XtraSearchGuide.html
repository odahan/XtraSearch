Guide d’utilisation

Recherchez des fichiers par nom ou par contenu dans les dossiers et les partages réseau que vous sélectionnez.

Lancer une recherche

  1. Dans Look in, indiquez un dossier ou choisissez-le avec Browse…. Séparez les chemins par ; et préfixez les exclusions par !. Vous pouvez utiliser une variable comme %TEMP%.
  2. Dans File name, saisissez * pour tous les fichiers ou *.txt;*.log pour limiter la recherche à deux extensions.
  3. Saisissez du texte dans Containing text, ou laissez ce champ vide pour chercher uniquement par nom. Lancez avec Start search ou F5.

Choisir le mode de recherche

  • Wildcard utilise * pour une suite de caractères et ? pour un caractère. Un nom simple sans joker ni point peut correspondre à une partie du nom.
  • Plain text cherche le texte saisi tel quel. Regex accepte une expression régulière, par exemple error\s+\d+.
  • Boolean accepte AND, OR, NOT, les guillemets et les parenthèses. Exemple "connection failed" AND NOT timeout. Boolean Regex traite les termes comme des expressions régulières.
  • Les termes peuvent correspondre sur des lignes différentes. Activez Match Boolean expressions line by line dans Options pour exiger une correspondance sur une seule ligne. Match case se règle séparément pour le nom et le contenu.

Affiner les critères

Include subfolders parcourt les sous-dossiers. Whole words limite la recherche de contenu aux mots entiers. Dans Options, réglez l’inclusion des fichiers masqués ou système, l’exclusion du contenu binaire et le nombre de workers (0 pour le mode automatique).

Dans Size & dates, les limites de taille sont strictes et exprimées en Ko de 1 024 octets. Saisissez les dates de création ou de modification au format yyyy-MM-dd. Les jours renseignés sont inclus en entier.

Formats pris en charge

La recherche de contenu prend en charge le texte UTF-8, l’Unicode avec marque BOM, les PDF contenant du texte, les fichiers DOCX, XLSX, PPTX et les documents OpenDocument.

Activez Search inside ZIP archives pour lire les entrées ZIP comme du texte. Les archives imbriquées et la reconnaissance de texte dans les PDF numérisés ne sont pas prises en charge.

Consulter les résultats

Pause suspend la recherche. Resume la reprend. Stop ou Échap l’arrête et conserve les résultats trouvés.

Sélectionnez un résultat pour afficher son aperçu. Ouvrez un fichier avec Entrée ou un double-clic. Utilisez Folder pour le localiser, Copy path pour copier son chemin et Search log pour consulter les erreurs.

Enregistrer ou exporter

Save search enregistre vos critères. Open… les recharge. Dans la liste de résultats, Export… produit un fichier CSV ou texte.

Search guide

Find files by name or by the text they contain in the folders and network shares you select.

Start a search

  1. Enter a folder in Look in or select it with Browse…. Separate paths with ; and prefix exclusions with !. Environment variables such as %TEMP% are supported.
  2. In File name, enter * for all files or *.txt;*.log to limit the search to two extensions.
  3. Enter text in Containing text or leave it blank to search by name alone. Choose Start search or press F5.

Choose a matching mode

  • Wildcard uses * for any number of characters and ? for one character. A simple name without a wildcard or dot can match part of a file name.
  • Plain text matches the entered text literally. Regex accepts a regular expression such as error\s+\d+.
  • Boolean accepts AND, OR, NOT, quoted phrases, and parentheses. Try "connection failed" AND NOT timeout. Boolean Regex treats terms as regular expressions.
  • Content terms can match across lines. Enable Match Boolean expressions line by line in Options to require a match on a single line. Set Match case separately for file names and content.

Narrow the search

Include subfolders searches nested folders. Whole words limits content matches to whole words. In Options, control hidden and system files, binary content, and parallel search workers (0 for automatic).

In Size & dates, size limits are exclusive and use KB of 1,024 bytes. Enter creation or modification dates as yyyy-MM-dd. The specified dates include the entire day.

Supported formats

Content search supports UTF-8, BOM-marked Unicode, PDFs with embedded text, DOCX, XLSX, PPTX, and OpenDocument files.

Enable Search inside ZIP archives to read ZIP entries as text. Nested archives and OCR for scanned PDFs are unsupported.

Review results

Pause suspends the search. Resume continues it. Stop or Esc ends the search and keeps results found so far.

Select a result to preview it. Open a file with Enter or a double-click. Use Folder to locate it, Copy path to copy its path, and Search log to review errors.

Save or export

Save search stores your criteria. Open… loads them again. Choose Export… in the results pane to write the result list to a CSV or text file.
